6. 파이썬 프로그래밍 기초: 자료형 (Chapter 2)
• 자료형의 중요성: 어떤 언어든 자료형을 이해하는 것은 해당 언어의 절반을 터득하는 것이라고 할 만큼 중요합니다. 예를 들어, 1 + 1이 숫자형에서는 2이지만, 문자열 자료형에서는 11이 됩니다.
• 변수(Variable):
    ◦ 변수는 값을 담는 **'상자'**와 같습니다.
    ◦ = 기호는 **'할당(Assignment)'**을 의미하며, 오른쪽의 값을 왼쪽의 변수에 담는다는 뜻입니다. 수학에서의 '같다'는 의미와 다릅니다. 예를 들어 a = a + 1은 기존 a 값에 1을 더한 후 다시 a에 담는다는 의미입니다.
    ◦ 주석(Comment): # 기호로 시작하는 한 줄 주석과 """ 또는 '''로 감싸는 여러 줄 주석이 있습니다. 코드 설명이나 비활성화에 사용되며, 컴퓨터는 주석을 읽지 않습니다.
• 숫자형 (Number Type):
    ◦ 정수형(Integer): 소수점이 없는 숫자 (예: 123, -45). type() 함수로 int임을 확인할 수 있습니다.
    ◦ 실수형(Float): 소수점이 있는 숫자 (예: 1.2, 4.24e10). type() 함수로 float임을 확인할 수 있습니다.
    ◦ 사칙연산: 덧셈(+), 뺄셈(-), 곱셈(*), 나눗셈(/).
    ◦ 거듭제곱: ** (예: 3 ** 4는 3의 4승).
    ◦ 나머지 연산: % (예: 7 % 3은 7을 3으로 나눈 나머지 1).
    ◦ 몫 연산: // (예: 7 // 3은 7을 3으로 나눈 몫 2).
    ◦ (참고: 8진수, 16진수, 과학적 표기법도 있으나 빈번히 사용되지는 않음).
• 문자열 (String):
    ◦ 생성 방법: 작은따옴표 ('...'), 큰따옴표 ("..."), 세 개의 작은따옴표 ('''...'''), 세 개의 큰따옴표 ("""...""")로 감싸서 만듭니다. 따옴표로 감싸면 숫자도 문자로 인식됩니다.
    ◦ 따옴표 포함: 문자열 안에 같은 종류의 따옴표를 포함하려면, 다른 종류의 따옴표로 문자열을 감싸거나 **백슬래시(\)**로 이스케이프해야 합니다.
    ◦ 여러 줄 문자열: \n (줄바꿈 문자) 또는 세 개의 따옴표로 감싸서 표현합니다.
    ◦ 문자열 연산:
        ▪ 연결: + 기호로 두 문자열을 연결합니다.
        ▪ 반복: * 기호와 숫자를 사용하여 문자열을 반복합니다 (문자열끼리 곱셈 불가).
    ◦ 길이 구하기: len() 함수를 사용하여 문자열의 길이를 구합니다 (공백 포함).
    ◦ 인덱싱 (Indexing): 문자열의 특정 위치에 있는 문자를 가져오는 방법.
        ▪ 0부터 시작: 인덱스는 0번부터 시작합니다.
        ▪ 음수 인덱스: 뒤에서부터 셀 때는 -1부터 시작합니다 (-1은 마지막 문자).
    ◦ 슬라이싱 (Slicing): 문자열의 특정 부분을 잘라 가져오는 방법.
        ▪ [시작번호:끝번호 미만] (끝번호는 포함되지 않음).
        ▪ [시작번호:]: 시작번호부터 끝까지.
        ▪ [:끝번호 미만]: 처음부터 끝번호 미만까지.
        ▪ [::간격]: 특정 간격으로 문자열을 건너뛰어 가져올 수 있습니다.
    ◦ 문자열은 변경 불가능(Immutable): 문자열의 특정 부분을 변경하려고 하면 오류가 발생합니다.
    ◦ 문자열 포맷팅: 문자열 안에 변수 값을 삽입하는 방법.
        ▪ % 연산자: %s (문자열), %d (정수), %f (실수) 등. %s는 모든 자료형을 수용합니다.
        ▪ .format() 메서드: 중괄호 {} 안에 변수 값을 넣고 format() 메서드에 값을 전달합니다. 순서 지정 {0}, 이름 지정 {name}도 가능합니다.
        ▪ F-string (가장 최신 권장 방식): 파이썬 3.6 이상에서 사용 가능하며, 문자열 앞에 f를 붙이고 중괄호 {} 안에 변수나 연산식을 직접 넣습니다. 가장 직관적이고 편리합니다.
        ▪ (참고: 정렬, 공백 채우기, 소수점 표현 등 다양한 포맷 옵션이 있으나, F-string으로도 대부분 구현 가능).
    ◦ 문자열 관련 함수 (메서드):
        ▪ count(): 특정 문자의 개수 세기.
        ▪ find(): 특정 문자열의 시작 인덱스 반환 (-1은 없음을 의미).
        ▪ index(): find()와 유사하나, 없으면 오류 발생.
        ▪ join(): 특정 문자열을 기준으로 리스트나 튜플의 요소를 연결.
        ▪ upper(): 모든 문자를 대문자로 변환.
        ▪ lower(): 모든 문자를 소문자로 변환.
        ▪ lstrip(): 왼쪽 공백 제거.
        ▪ rstrip(): 오른쪽 공백 제거.
        ▪ strip(): 양쪽 공백 제거.
        ▪ replace(): 특정 문자열을 다른 문자열로 교체.
        ▪ split(): 특정 기준(기본은 공백)으로 문자열을 분리하여 리스트로 반환.
• 리스트 (List):
    ◦ 개념: 여러 개의 값을 순서대로 담을 수 있는 '서랍장'과 같은 자료형. **뮤터블(Mutable, 변경 가능)**하며, 서로 다른 자료형의 값을 함께 담을 수 있습니다.
    ◦ 생성 방법: 대괄호 [] 안에 콤마로 구분하여 요소들을 넣습니다.
    ◦ 인덱싱 및 슬라이싱: 문자열과 거의 동일합니다 (0-기반 인덱스, 음수 인덱스, 범위 슬라이싱).
    ◦ 연산: + (리스트 연결), * (리스트 반복).
    ◦ 길이 구하기: len() 함수.
    ◦ 값 변경: 인덱스를 사용하여 특정 위치의 값을 변경할 수 있습니다.
    ◦ 요소 삭제: del 키워드를 사용하거나 슬라이싱으로 삭제할 수 있습니다.
    ◦ 메서드:
        ▪ append(): 리스트 맨 뒤에 요소 추가.
        ▪ insert(): 특정 인덱스에 요소 삽입.
        ▪ extend(): 다른 리스트(또는 이터러블)의 요소들을 리스트에 확장하여 추가. (append()는 리스트 자체를 통째로 추가, extend()는 요소들을 펼쳐서 추가).
        ▪ remove(): 리스트에서 첫 번째로 나타나는 특정 값을 삭제.
        ▪ pop(): 리스트의 마지막 요소를 끄집어내면서 삭제 (인덱스 지정 시 해당 인덱스 요소). (끄집어낸 값을 반환함).
        ▪ sort(): 리스트를 오름차순으로 정렬. (내림차순은 reverse=True 옵션 사용)
        ▪ reverse(): 리스트의 요소 순서를 뒤집음.
        ▪ index(): 특정 값의 인덱스 반환 (없으면 오류).
        ▪ count(): 특정 값의 개수 세기.
    ◦ 자료형 변환: str() (문자열), int() (정수), list() (리스트) 등으로 자료형을 변환할 수 있습니다. 다른 자료형끼리 연산 시 오류가 발생할 수 있으므로 형 변환이 필요할 수 있습니다.
    ◦ 중복 제거: 리스트를 set()으로 변환하면 중복된 요소가 제거되고, 다시 list()로 변환하여 리스트로 활용할 수 있습니다.
• 튜플 (Tuple):
    ◦ 개념: 리스트와 유사하지만, **불변(Immutable, 변경 불가능)**이라는 가장 큰 차이점이 있습니다. 즉, 한번 생성되면 요소를 추가, 변경, 삭제할 수 없습니다. 마치 '자물쇠로 잠근 서랍장'.
    ◦ 생성 방법: 소괄호 ()로 감싸거나, 콤마(,)로 구분하여 요소를 넣습니다. (단일 요소 튜플은 (값,)처럼 콤마를 붙여야 함).
    ◦ 인덱싱 및 슬라이싱: 리스트와 동일하게 사용 가능합니다. (슬라이싱은 원본 튜플을 변경하는 것이 아니라 새로운 튜플을 반환).
    ◦ 연산: + (튜플 연결), * (튜플 반복). (새로운 튜플을 생성하는 것이므로 원본 튜플은 변경되지 않음).
    ◦ 길이 구하기: len() 함수.
    ◦ 불가능한 작업: sort(), insert(), remove(), pop() 등 요소를 변경하는 모든 메서드는 사용할 수 없습니다.
    ◦ 뮤터블(Mutable) vs. 이뮤터블(Immutable):
        ▪ 이뮤터블: 정수, 실수, 문자열, 튜플 (값 변경 불가능).
        ▪ 뮤터블: 리스트, 딕셔너리, 집합 (값 변경 가능).
• 딕셔너리 (Dictionary):
    ◦ 개념: **키(Key)**와 값(Value) 쌍으로 이루어진 자료형으로, 실제 사전과 유사합니다. 키를 통해 값을 찾습니다. 다른 언어의 Map, Object, JSON과 유사합니다.
    ◦ 생성 방법: 중괄호 {} 안에 키: 값 형태로 콤마로 구분하여 넣습니다.
    ◦ 값 추가/변경: 딕셔너리[새 키] = 새 값 또는 딕셔너리[기존 키] = 새 값으로 추가하거나 변경합니다.
    ◦ 값 삭제: del 딕셔너리[키] 또는 딕셔너리.clear() (모두 삭제).
    ◦ 값 얻기: 딕셔너리[키] 또는 딕셔너리.get(키).
        ▪ 딕셔너리[키]는 키가 없으면 KeyError 발생.
        ▪ 딕셔너리.get(키)는 키가 없으면 None을 반환하거나, 두 번째 인수로 기본값 지정 가능.
    ◦ 주의사항:
        ▪ 키는 중복될 수 없습니다: 중복되면 마지막 값으로 덮어씌워집니다.
        ▪ 키는 변경 불가능한 자료형이어야 합니다: 리스트와 같은 뮤터블 자료형은 키로 사용할 수 없습니다.
    ◦ 메서드:
        ▪ keys(): 딕셔너리의 모든 키를 딕트 키즈(dict_keys) 객체로 반환 (리스트로 변환 가능). 주로 반복문(for)에서 사용됩니다.
        ▪ values(): 딕셔너리의 모든 값(value)을 딕트 밸류(dict_values) 객체로 반환.
        ▪ items(): 딕셔너리의 모든 키-값 쌍을 딕트 아이템(dict_items) 객체로 반환 (각 쌍은 튜플 형태).
        ▪ clear(): 딕셔너리의 모든 키-값 쌍을 삭제.
        ▪ in 연산자: 특정 키가 딕셔너리 안에 존재하는지 확인하여 True 또는 False 반환.
• 집합 (Set):
    ◦ 개념: 순서가 없고 중복을 허용하지 않는 자료형.
    ◦ 생성 방법: set() 함수에 리스트 등을 전달하거나, 중괄호 {} 안에 요소들을 콤마로 구분하여 직접 넣습니다. (빈 집합은 {} 대신 set()으로 생성해야 함, {}는 빈 딕셔너리)
    ◦ 특징:
        ▪ 순서 없음: 인덱싱이나 슬라이싱이 불가능합니다.
        ▪ 중복 제거: 중복된 값은 자동으로 제거됩니다.
    ◦ 집합 연산:
        ▪ 교집합(Intersection): & 연산자 또는 intersection() 메서드.
        ▪ 합집합(Union): | 연산자 또는 union() 메서드.
        ▪ 차집합(Difference): - 연산자 또는 difference() 메서드.
    ◦ 메서드:
        ▪ add(): 요소 하나 추가.
        ▪ update(): 여러 요소 추가 (리스트, 튜플 등 이터러블 형태).
        ▪ remove(): 특정 값 제거.
    ◦ 활용: 중복된 요소가 많은 리스트에서 중복을 제거할 때 유용하게 사용됩니다.
• 불 (Boolean):
    ◦ 개념: 참(True)과 거짓(False)을 나타내는 자료형. **조지 불(George Boole)**이라는 수학자의 이름에서 유래.
    ◦ 값: True, False (반드시 첫 글자는 대문자).
    ◦ 활용: 주로 조건문(if), 반복문(while) 등 프로그램의 흐름을 제어하는 데 사용됩니다.
    ◦ 자료형의 참과 거짓 (Truthiness & Falsiness):
        ▪ 거짓(False)으로 간주되는 값: None, 0 (숫자), 빈 문자열 (''), 빈 리스트 ([]), 빈 튜플 (()), 빈 딕셔너리 ({}), 빈 집합 (set()).
        ▪ 참(True)으로 간주되는 값: 위 거짓 값을 제외한 모든 값.
        ▪ bool() 함수로 특정 값의 참/거짓 속성을 확인할 수 있습니다.
• 변수 심화 (Advanced Variables):
    ◦ 메모리 주소: 변수에 값을 담는다는 것은 실제로는 메모리(RAM) 상의 주소값을 담는 것입니다. id() 함수를 통해 변수가 참조하는 객체의 메모리 주소를 확인할 수 있습니다.
    ◦ 변수 복사 시 주의사항:
        ▪ b = a와 같이 변수를 할당하면, a가 참조하는 객체의 주소값을 b에 복사하므로, a와 b는 같은 객체를 참조하게 됩니다. 따라서 한쪽의 값을 변경하면 다른 쪽도 영향을 받습니다.
        ▪ 이를 방지하려면 **'깊은 복사'**를 해야 합니다.
            • 슬라이싱: b = a[:]와 같이 리스트를 슬라이싱하면 새로운 리스트 객체가 생성되어 복사됩니다.
            • copy 모듈: copy.copy() (얕은 복사) 또는 copy.deepcopy() (깊은 복사) 함수를 사용합니다. (리스트 자체의 copy() 메서드도 있음).
    ◦ 다중 할당: a, b = 10, 20과 같이 여러 변수에 한 번에 값을 할당할 수 있습니다.
    ◦ 값 교환: a, b = b, a와 같이 한 줄로 두 변수의 값을 쉽게 교환할 수 있습니다. (다른 언어에서는 임시 변수가 필요함).
7. 프로그램의 구조: 제어문 (Chapter 3)
• 조건문 (Conditional Statements): 특정 조건에 따라 프로그램의 실행 흐름을 변경하는 구문.
    ◦ if 구문: if 조건: 실행할 코드 형태로 사용. 조건이 True일 때만 실행됩니다.
    ◦ else 구문: else: 실행할 코드 형태로, if 조건이 False일 때 실행됩니다.
    ◦ elif (else if): if와 else 사이에 여러 조건을 추가할 때 사용합니다.
    ◦ 들여쓰기(Indentation): 파이썬에서 조건문의 코드 블록은 **들여쓰기(탭 또는 공백 4칸)**로 구분됩니다. 들여쓰기가 맞지 않으면 IndentationError가 발생합니다.
    ◦ 콜론(:): if, elif, else 뒤에는 반드시 콜론이 와야 합니다.
    ◦ 비교 연산자: > (크다), < (작다), == (같다), != (같지 않다), >= (크거나 같다), <= (작거나 같다).
    ◦ 논리 연산자:
        ▪ and: 두 조건 모두 True일 때 True.
        ▪ or: 두 조건 중 하나라도 True일 때 True.
        ▪ not: 조건의 불리언 값을 반전 (True -> False, False -> True).
    ◦ in, not in 연산자: 특정 값이 리스트, 튜플, 문자열 등 '이터러블' 객체 안에 포함되어 있는지 확인합니다.
    ◦ pass 키워드: 아무 작업도 수행하지 않고 다음으로 넘어갈 때 사용합니다.
    ◦ 한 줄 조건문 (조건부 표현식): 참일때_값 if 조건 else 거짓일때_값 형태로 한 줄로 조건식을 표현할 수 있습니다 (일종의 '패션 코딩'으로 불리기도 함).
• 반복문 (Loops): 반복적인 작업을 자동으로 수행하는 구문.
    ◦ while 문: 조건이 True인 동안 코드 블록을 계속 반복 실행합니다.
        ▪ break: while 루프를 강제로 종료하고 빠져나옵니다.
        ▪ continue: 현재 반복을 건너뛰고 while 조건으로 돌아가 다음 반복을 시작합니다 (아래 코드는 실행되지 않음).
        ▪ 무한 루프: while True: 형태로 무한히 반복되며, break 조건이 없으면 계속 실행됩니다. (Ctrl + C로 강제 종료 가능).
        ▪ 디버깅: VS Code의 디버깅 기능을 통해 코드의 실행 흐름을 한 줄씩 확인하며 변수 값의 변화를 추적할 수 있습니다. ('버그'라는 용어는 실제 컴퓨터에 들어간 벌레에서 유래).
        ▪ 축약 연산자: 변수 += 값 (변수 = 변수 + 값과 동일), 변수 -= 값 등.
    ◦ for 문: 리스트, 튜플, 문자열 등 이터러블(iterable) 객체의 각 요소를 순회하며 코드 블록을 반복 실행합니다.
        ▪ for 변수 in 이터러블:. 이터러블에서 요소를 하나씩 꺼내와 변수에 할당합니다.
        ▪ range() 함수: 지정된 범위의 숫자를 생성하는 이터러블 객체를 반환합니다. range(시작, 끝 미만) 형태로 사용.
        ▪ 중첩 for 문: 반복문 안에 또 다른 반복문을 넣을 수 있습니다 (예: 구구단).
        ▪ print() 함수의 end 매개변수: print()는 기본적으로 마지막에 줄바꿈 문자(\n)를 추가하지만, end=''와 같이 end에 다른 값을 지정하여 줄바꿈 대신 해당 값을 추가할 수 있습니다.
        ▪ 리스트 컴프리헨션 (List Comprehension): [표현식 for 변수 in 이터러블 if 조건] 형태로 한 줄로 리스트를 생성하는 간결한 방법 (일종의 '패션 코딩'이지만 실용적). 조건문을 추가하여 원하는 요소만 선택할 수도 있습니다.
8. 파이썬 입출력 및 모듈/패키지/예외 처리 (Chapter 4, 5)
• 함수 (Functions): 특정 작업을 수행하는 코드 블록을 정의하고 재사용하는 방법.
    ◦ 정의: def 함수이름(매개변수):.
    ◦ 매개변수 (Parameters) & 인수 (Arguments): 함수 정의 시 사용되는 변수는 매개변수, 함수 호출 시 전달되는 값은 인수. (두 용어는 종종 혼용됨).
    ◦ 반환값 (Return Value): return 키워드를 사용하여 함수의 결과를 반환합니다.
        ▪ 함수는 입력값과 반환값이 없을 수도 있습니다.
        ▪ return을 만나면 함수는 즉시 종료됩니다.
        ▪ 함수의 반환값은 항상 하나입니다 (여러 값을 반환하는 것처럼 보이지만 실제로는 튜플로 묶어서 반환).
    ◦ 매개변수 지정 호출: 함수(매개변수_이름=값) 형태로 호출할 수 있어, 순서와 관계없이 값을 전달할 수 있습니다.
    ◦ 가변 인자 (*args, **kwargs):
        ▪ *매개변수_이름: 개수가 정해지지 않은 위치 인자(positional arguments)를 튜플 형태로 받습니다.
        ▪ **매개변수_이름: 개수가 정해지지 않은 키워드 인자(keyword arguments)를 딕셔너리 형태로 받습니다.
    ◦ 매개변수 기본값 설정: def 함수이름(매개변수=기본값): 형태로 기본값을 지정할 수 있습니다. (기본값이 있는 매개변수는 항상 맨 뒤에 정의해야 함).
    ◦ 변수의 효력 범위 (Scope):
        ▪ 지역 변수 (Local Variable): 함수 내부에서 정의된 변수로, 함수 실행이 끝나면 사라집니다.
        ▪ 전역 변수 (Global Variable): 함수 외부에서 정의된 변수로, 프로그램 전체에서 접근 가능합니다.
        ▪ 함수 내에서 전역 변수를 직접 변경하려면 global 키워드를 사용해야 합니다 (남용 시 코드 복잡해짐).
        ▪ 뮤터블(리스트, 딕셔너리) 객체는 함수 내부에서 변경될 때, 원본 전역 객체에도 영향을 미칠 수 있습니다.
    ◦ 람다 함수 (Lambda Function): lambda 매개변수: 표현식 형태로 한 줄로 작성하는 익명 함수. 주로 간단한 함수를 즉석에서 만들 때 사용하며, 이름을 지정하지 않고 변수에 담거나 다른 함수의 인수로 전달할 수 있습니다.
• 사용자 입출력 (User Input/Output):
    ◦ input() 함수: 사용자로부터 키보드 입력을 받아 문자열(string) 형태로 반환합니다. 안내 문구를 인수로 전달할 수 있습니다.
    ◦ print() 함수: 인수로 전달된 값을 화면에 출력합니다.
        ▪ 쉼표(,)로 여러 값을 전달하면 자동으로 공백으로 구분하여 출력합니다.
        ▪ end 매개변수: 출력 후 마지막에 추가될 문자열을 지정합니다 (기본값은 줄바꿈 \n).
        ▪ sep 매개변수: 여러 값을 출력할 때 구분자로 사용될 문자열을 지정합니다.
• 파일 읽고 쓰기 (File I/O):
    ◦ open() 함수: 파일을 열 때 사용하며, 파일 경로와 '모드'를 인수로 받습니다.
        ▪ 'w' (write): 쓰기 모드 (파일이 없으면 생성, 있으면 덮어쓰기).
        ▪ 'r' (read): 읽기 모드.
        ▪ 'a' (append): 추가 모드 (파일이 없으면 생성, 있으면 기존 내용 뒤에 추가).
    ◦ 파일 경로: 상대 경로 (현재 스크립트 위치 기준) 또는 절대 경로 (루트 디렉토리 기준)를 사용합니다. 한글 경로 사용 시 **인코딩(encoding='utf-8')**을 지정해야 깨짐을 방지할 수 있습니다.
    ◦ 쓰기: 파일객체.write(내용).
    ◦ 읽기:
        ▪ 파일객체.readline(): 파일에서 한 줄씩 읽어옵니다.
        ▪ 파일객체.readlines(): 파일의 모든 줄을 읽어와 각 줄을 요소로 하는 리스트로 반환합니다.
        ▪ 파일객체.read(): 파일의 모든 내용을 하나의 문자열로 읽어옵니다.
        ▪ for line in 파일객체:: 파일 객체를 직접 for 문으로 순회하면 한 줄씩 읽어올 수 있습니다.
    ◦ f.close(): 파일을 사용한 후에는 반드시 닫아주어야 합니다.
    ◦ with 문: with open(...) as f: 형태로 사용하면, 코드 블록을 벗어날 때 파일이 자동으로 닫힙니다.
• 명령어 프롬프트 입출력 (Command Line Arguments):
    ◦ sys 모듈: 파이썬 스크립트를 명령 프롬프트에서 실행할 때 함께 전달되는 인자(arguments)를 처리하는 데 사용됩니다.
    ◦ sys.argv: 스크립트 실행 시 전달된 모든 인자들을 리스트 형태로 저장합니다. (첫 번째 요소 sys.argv는 스크립트 파일 이름 자체).
• 클래스 (Classes): 객체지향 프로그래밍의 핵심 개념으로, **변수(속성)**와 **함수(메서드)**를 미리 정의해 놓은 **'틀' 또는 '설계도'**입니다.
    ◦ 객체(Object) / 인스턴스(Instance): 클래스라는 틀에서 찍어내어 실제 메모리에 생성된 결과물. 객체는 '값'(변수)과 '행동'(함수/메서드)이라는 두 가지 속성을 가집니다.
    ◦ 클래스 정의: class 클래스이름: (클래스 이름은 컨벤션 상 첫 글자를 대문자로).
    ◦ 인스턴스 생성: 변수 = 클래스이름().
    ◦ self: 클래스 메서드의 첫 번째 매개변수로, 해당 메서드를 호출한 '객체 자신'을 나타냅니다. 파이썬에서 메서드를 정의할 때 반드시 포함해야 합니다.
    ◦ 객체 변수 (Instance Variables): self.변수명 형태로 정의하며, 각 객체(인스턴스)마다 고유한 값을 가집니다.
    ◦ 생성자 (__init__): __init__(self, ...) 는 클래스로부터 객체가 생성될 때 가장 먼저 자동 실행되는 특별한 메서드. 객체의 초기 속성을 설정하는 데 사용되며, 객체 생성 시 필수적으로 전달되어야 하는 인자를 강제할 수 있습니다.
    ◦ 상속 (Inheritance): 다른 클래스(부모 클래스)의 기능(속성과 메서드)을 물려받아 새로운 클래스(자식 클래스)를 만드는 기능. class 자식클래스(부모클래스): 형태로 선언. 부모 클래스의 기능을 재사용하여 코드의 중복을 줄이고 확장성을 높일 수 있습니다.
    ◦ 메서드 오버라이딩 (Method Overriding): 자식 클래스가 부모 클래스에 정의된 메서드와 동일한 이름의 메서드를 재정의하는 것. 자식 클래스에서 오버라이딩된 메서드가 호출되면 부모의 메서드보다 자식의 메서드가 우선적으로 실행됩니다.
    ◦ 클래스 변수 (Class Variables): 클래스 내부에 정의되며, 해당 클래스로부터 생성된 모든 객체가 공유하는 변수. 모든 객체가 동일한 값을 가져야 할 때 사용됩니다.
• 모듈 (Modules): 함수, 변수, 클래스 등을 모아 놓은 파이썬 파일입니다.
    ◦ 불러오기:
        ▪ import 모듈이름: 모듈 전체를 불러옵니다 (모듈이름.함수명()).
        ▪ from 모듈이름 import 함수명: 특정 함수나 변수, 클래스만 불러와서 바로 사용할 수 있습니다 (함수명()). 여러 개를 불러올 때는 콤마(,)로 구분합니다.
        ▪ import 모듈이름 as 별명: 모듈 이름을 줄여서 별명으로 사용할 수 있습니다.
    ◦ if __name__ == "__main__":: 해당 모듈 파일이 직접 실행될 때만 특정 코드를 실행하도록 하는 관용적인 표현. (다른 파일에서 import될 때는 실행되지 않음).
    ◦ 모듈 경로: sys.path 리스트에 모듈이 있는 디렉토리 경로를 추가하여 파이썬이 해당 모듈을 찾을 수 있도록 할 수 있습니다.
• 패키지 (Packages): 모듈의 집합으로, 관련된 여러 모듈을 디렉토리(폴더) 형태로 구조화한 것입니다.
    ◦ __init__.py: 패키지 디렉토리 안에 존재하여 해당 디렉토리가 파이썬 패키지임을 알리는 역할을 합니다. (파이썬 3.3부터는 필수가 아님).
    ◦ 패키지 내 모듈 불러오기: from 패키지이름.모듈이름 import 함수명 또는 import 패키지이름.모듈이름 형태로 사용합니다.
• 예외 처리 (Exception Handling): 프로그램 실행 중 발생하는 **오류(Error)**에 대해 적절하게 대처하여 프로그램이 비정상적으로 종료되는 것을 방지하는 기법.
    ◦ 오류 발생 시점: 파일이 없거나(FileNotFoundError), 0으로 나누거나(ZeroDivisionError), 리스트 인덱스 범위를 벗어나거나(IndexError) 할 때 발생합니다.
    ◦ try-except 구문:
        ▪ try: 오류가 발생할 수 있는 코드를 작성합니다.
        ▪ except 오류타입 as 별칭: try 블록에서 특정 오류가 발생하면 해당 except 블록의 코드가 실행됩니다. 오류 메시지를 별칭으로 받을 수 있습니다. 여러 except 블록을 두어 다양한 오류에 대처할 수 있습니다.
        ▪ else: try 블록에서 오류가 발생하지 않았을 때 실행됩니다.
        ▪ finally: 오류 발생 여부와 상관없이 항상 마지막에 실행되는 코드를 작성합니다 (예: 파일 닫기).
    ◦ raise: 프로그래머가 일부러 오류를 발생시킬 때 사용합니다.
    ◦ 사용자 정의 예외: Exception 클래스를 상속받아 자신만의 오류 클래스를 만들 수 있습니다.
• 내장 함수 (Built-in Functions), 표준 라이브러리 (Standard Library), 외부 라이브러리 (External Libraries):
    ◦ "Don't reinvent the wheel": 이미 구현된 기능이 있다면 직접 다시 만들지 않고 가져다 쓰는 것이 효율적입니다.
    ◦ 내장 함수: 파이썬 인터프리터에 기본적으로 내장되어 있어 import 없이 바로 사용할 수 있는 함수들 (예: print(), input(), len(), type(), int(), str(), abs(), all(), any()).
    ◦ 표준 라이브러리: 파이썬 설치 시 기본적으로 포함되어 있지만, 사용하려면 import 해야 하는 모듈들 (예: datetime (날짜/시간), time (시간 관련), math (수학 연산), sys (시스템 관련), os (운영체제 상호작용)).
    ◦ 외부 라이브러리: 다른 개발자들이 만들어서 인터넷에 공개한 모듈이나 패키지.
        ▪ **pip (파이썬 패키지 설치 도구)**를 이용하여 설치합니다 (pip install 패키지이름).
        ▪ PyPI(Python Package Index)에서 다양한 외부 라이브러리를 검색할 수 있습니다.
        ▪ 설치 후에는 import하여 사용하며, 각 라이브러리마다 사용법이 다릅니다 (공식 문서나 구글링, ChatGPT를 통해 학습). (예: Faker (가짜 데이터 생성), pandas (데이터 분석), numpy (수치 연산), tensorflow (AI/ML)).
9. 파이썬 프로그래밍 문제 해결 (Chapter 6)
• 문제 해결 사고 흐름:
    1. 입력(Input)과 출력(Output) 정의: 프로그램이 무엇을 받아 무엇을 내놓을지 명확히 합니다.
    2. 기능 단위로 분리: 큰 문제를 작은 기능들로 나눕니다.
    3. 코드 구현 및 테스트: 각 기능을 구현하고 테스트합니다.
• 예제 실습:
    ◦ 구구단 2단 출력: 반복문(for 또는 while)과 리스트를 활용하여 N단을 출력하는 함수 구현.
    ◦ 3과 5의 배수 합산: 1부터 999까지의 숫자 중 3 또는 5의 배수를 찾아 합산하는 문제. (% 연산자와 or 조건문 활용, 공배수 중복 더하기 방지).
    ◦ 게시판 페이징: 총 게시물 수와 페이지당 게시물 수를 받아 총 필요한 페이지 수를 계산하는 문제. (나머지 연산 및 조건문으로 예외 처리).
    ◦ 간단한 메모장: 파일 입출력(open, write, read)과 명령행 인자(sys.argv)를 활용하여 메모 추가 및 조회 기능 구현.
    ◦ 탭 문자 공백으로 변환: 파일 읽기, 문자열 replace() 메서드를 사용하여 탭 문자를 공백 4개로 변환 후 새 파일에 저장.
    ◦ 하위 디렉토리 파이썬 파일 검색: os 모듈(os.listdir, os.path.join, os.path.isdir, os.path.splitext)을 활용하여 특정 디렉토리 하위의 모든 파이썬 파일을 찾는 프로그램 구현. 재귀 함수 개념을 사용하여 하위 디렉토리를 탐색하고, try-except로 접근 권한 오류를 처리합니다. (os.walk()를 사용하면 더 간결하게 구현 가능).
10. 파이썬 심화 개념 (Chapter 7)
• 파이썬과 유니코드:
    ◦ 컴퓨터의 문자 처리: 컴퓨터는 0과 1만 인식하므로, 문자는 숫자로 변환되어 처리됩니다.
    ◦ ASCII: 초기에 미국에서 만들어진 문자 인코딩 표준 (영어만 표현).
    ◦ 유니코드: 모든 나라의 문자를 포함하도록 설계된 국제 표준. 파이썬 3부터 모든 문자열은 기본적으로 유니코드로 처리됩니다.
    ◦ 인코딩 (.encode()): 문자열을 바이트(bytes) 표현으로 변환. (예: utf-8, euc-kr 등).
    ◦ 디코딩 (.decode()): 바이트 문자열을 다시 원래 문자열로 변환. (인코딩 시 사용했던 방식과 동일한 방식으로 디코딩해야 함).
    ◦ 파일 입출력과 인코딩: 파일을 열거나 저장할 때 encoding 매개변수를 사용하여 인코딩 방식을 명시해야 문자열 깨짐을 방지할 수 있습니다.
• 클로저와 데코레이터:
    ◦ 클로저 (Closure): 함수 안에 내부 함수를 구현하고, 그 내부 함수를 리턴하는 함수. 내부 함수는 외부(둘러싼) 함수의 변수들을 기억하고 접근할 수 있습니다. 클래스 대신 함수로 특정 동작을 미리 설정해 둔 함수를 만들 때 유용합니다.
    ◦ 데코레이터 (Decorator): 기존 함수를 수정하지 않고 추가 기능을 덧씌우는 데 사용되는 클로저의 한 형태.
        ▪ 사용법: @데코레이터함수명을 꾸밀 함수 위에 붙입니다.
        ▪ 함수 실행 시간 측정, 로깅, 권한 확인 등 다양한 용도로 활용됩니다.
• 이터레이터와 제너레이터:
    ◦ 이터러블 (Iterable): for 루프 등으로 반복 가능한 객체 (예: 리스트, 튜플, 문자열).
    ◦ 이터레이터 (Iterator): next() 함수를 호출할 때마다 다음 값을 순서대로 반환하는 객체. 더 이상 반환할 값이 없으면 StopIteration 예외 발생. iter() 함수로 이터러블을 이터레이터로 변환할 수 있습니다. (값을 한 번 읽으면 다시 읽을 수 없음).
    ◦ 제너레이터 (Generator): yield 키워드를 사용하여 이터레이터를 생성하는 함수.
        ▪ 느긋한 계산법 (Lazy Evaluation): 필요할 때마다 값을 하나씩 생성하여 반환하므로, 모든 데이터를 메모리에 미리 로드하지 않아 메모리 사용을 효율적으로 할 수 있습니다. 대량의 데이터를 처리하거나 시간이 오래 걸리는 함수 호출에 유용합니다.
        ▪ 제너레이터 표현식: (표현식 for 변수 in 이터러블 if 조건) 형태로, 리스트 컴프리헨션과 유사하지만 소괄호로 감싸서 제너레이터를 간결하게 만듭니다.
• 파이썬 타입 어노테이션 (Type Annotation):
    ◦ 파이썬 3.5부터 추가된 기능으로, 변수와 함수의 **'타입 힌트'**를 제공합니다.
    ◦ 동적 언어 vs. 정적 언어:
        ▪ 파이썬: 동적 언어로, 변수의 타입이 프로그램 실행 중에 변경될 수 있습니다. (유연하나, 큰 프로젝트에서 버그 발생 가능성).
        ▪ Java: 정적 언어로, 변수의 타입을 컴파일 시점에 지정하며, 한 번 지정된 타입은 변경할 수 없습니다.
    ◦ 타입 어노테이션의 역할: 파이썬은 타입 어노테이션을 강제하지 않습니다. 코드를 실행할 때 타입이 맞지 않아도 오류가 발생하지 않으며, 주로 코드 가독성을 높이고 IDE나 외부 도구(예: mypy)의 타입 검사에 도움을 줍니다.
11. 정규 표현식 (Regular Expressions) (Chapter 8)
• 개념: 복잡한 문자열에서 특정 패턴을 찾거나 처리할 때 사용하는 기법으로, 파이썬에만 고유한 것이 아닌 일종의 '형식 언어'.
• 활용: 주민등록번호나 이메일 주소처럼 일정한 규칙을 가진 문자열을 찾아내거나 변형하는 데 사용하면 코드를 매우 간결하게 만들 수 있습니다.
• 메타 문자: 정규 표현식에서 특별한 의미를 가지는 문자.
    ◦ 문자 클래스 ([]): 대괄호 안의 문자 중 하나와 매치 (예: [abc]는 'a', 'b', 'c' 중 하나). 하이픈(-)으로 범위 지정 가능 (예: [a-z]는 모든 소문자 알파벳).
    ◦ . (점): 줄바꿈 문자(\n)를 제외한 모든 문자와 매치.
    ◦ * (별표): 바로 앞 문자가 0번 이상 반복.
    ◦ + (플러스): 바로 앞 문자가 1번 이상 반복.
    ◦ {m, n} (중괄호): 바로 앞 문자가 최소 m번, 최대 n번 반복.
    ◦ ? (물음표): 바로 앞 문자가 0번 또는 1번 반복.
    ◦ | (파이프): '또는' (OR)의 의미.
    ◦ ^ (캐럿): 문자열의 시작과 매치. (re.M 옵션 사용 시 각 줄의 시작).
    ◦ $ (달러): 문자열의 끝과 매치. (re.M 옵션 사용 시 각 줄의 끝).
    ◦ \A: 문자열의 처음과 매치 (멀티라인 옵션과 무관).
    ◦ \Z: 문자열의 끝과 매치 (멀티라인 옵션과 무관).
    ◦ \b: 단어 경계 (공백, 문장 부호 등으로 구분되는 단어의 시작 또는 끝).
    ◦ \B: 단어 경계가 아님.
    ◦ 축약 메타 문자: \d (숫자), \w (문자+숫자), \s (공백 문자) 등.
• 파이썬에서 정규 표현식 사용: re 모듈을 import하여 사용.
    ◦ re.compile(패턴): 정규식 패턴을 컴파일하여 '패턴 객체' 생성.
    ◦ 패턴 객체 메서드:
        ▪ match(): 문자열의 처음부터 패턴과 매치되는지 검사. (성공 시 매치 객체 반환, 실패 시 None).
        ▪ search(): 문자열의 전체에서 패턴과 매치되는지 탐색. (매치되는 첫 번째 부분에 대해 매치 객체 반환).
        ▪ findall(): 패턴과 매치되는 모든 문자열을 찾아 리스트로 반환.
        ▪ finditer(): 패턴과 매치되는 모든 '매치 객체'를 찾아 이터레이터로 반환.
    ◦ 매치 객체 메서드: match() 또는 search() 성공 시 반환되는 객체.
        ▪ group(): 매치된 문자열 반환 (인덱스 지정 시 특정 그룹).
        ▪ start(): 매치된 문자열의 시작 인덱스.
        ▪ end(): 매치된 문자열의 끝 인덱스.
        ▪ span(): 매치된 문자열의 시작과 끝 인덱스를 튜플로 반환.
    ◦ 컴파일 옵션:
        ▪ re.S 또는 re.DOTALL: . (점) 메타 문자가 줄바꿈 문자까지 포함하여 매치.
        ▪ re.I 또는 re.IGNORECASE: 대소문자 구분 없이 매치.
        ▪ re.M 또는 re.MULTILINE: ^ (시작)와 $ (끝) 메타 문자가 각 줄의 시작/끝에도 적용.
        ▪ re.X 또는 re.VERBOSE: 정규식에 주석을 달거나 여러 줄로 나누어 작성하여 가독성을 높임.
    ◦ 로우 스트링 (Raw String) r'': 문자열 앞에 r을 붙여 역슬래시(\)를 이스케이프 문자로 해석하지 않고 리터럴 문자로 취급하도록 합니다. 정규 표현식에서 역슬래시가 많이 사용되므로 혼란을 방지하기 위해 권장됩니다.
• 그룹핑 (Grouping): 소괄호 ()를 사용하여 정규식의 특정 부분을 그룹으로 묶는 기능.
    ◦ 그룹 재참조: \1, \2 등으로 앞서 묶은 그룹을 다시 참조할 수 있습니다.
    ◦ 이름 붙이기: (?P<이름>패턴) 형태로 그룹에 이름을 부여하여 group('이름')으로 참조 가능.
• 전방 탐색 (Lookahead): 패턴을 검사하지만, 매치 결과에는 포함하지 않는 기능.
    ◦ 긍정형 ((?=...)): 패턴이 매치되어야 하지만, 결과에 포함되지 않음.
    ◦ 부정형 ((?!...)): 패턴이 매치되지 않아야 하지만, 결과에 포함되지 않음.
• 문자열 바꾸기 (sub()): 패턴객체.sub(바꿀문자열, 원본문자열) 형태로 사용하여 패턴과 일치하는 부분을 다른 문자열로 교체.
• 그리디(Greedy) vs. 논그리디(Non-Greedy):
    ◦ 그리디: *나 +와 같은 반복 메타 문자는 기본적으로 가장 긴 문자열과 매치되려는 '탐욕스러운' 속성을 가집니다.
    ◦ 논그리디: 반복 메타 문자 뒤에 ?를 붙여 가장 짧은 문자열과 매치되도록 합니다 (예: *?, +?).
• 정규 표현식 학습 권장 사항: 정규 표현식 문법은 복잡하므로, 모든 것을 암기하기보다는 필요한 경우 ChatGPT와 같은 AI 도구를 활용하거나 관련 문서를 찾아보는 것이 더 효율적입니다.
12. 마치며
이 강의는 파이썬의 핵심 문법과 개념을 자세히 다루며, 실제 코드를 통해 실습하고 디버깅하는 방법을 병행하여 학습자의 이해를 돕습니다. 기초 자료형부터 조건문, 반복문, 함수, 클래스, 모듈, 예외 처리, 그리고 유니코드, 클로저, 제너레이터, 타입 어노테이션, 정규 표현식과 같은 심화 내용까지 폭넓게 다룹니다. 또한, 실제 문제 해결 예시를 통해 프로그래밍적 사고 방식을 익힐 수 있도록 안내합니다. 최신 AI 도구(ChatGPT)의 활용법까지 제시하여 학습 부담을 줄이고 실용적인 학습을 강조하는 점이 특징입니다.
이 강의를 통해 파이썬 기초 과정을 마스터했다면, 이를 바탕으로 웹 개발, 업무 자동화, 인공지능/머신러닝, 주식/비트코인 투자 자동화 등 다양한 분야로 파이썬 활용 범위를 넓힐 수 있을 것입니다.

파이썬의 특징:
• 인간다운 언어: 영어를 아는 사람이라면 코드를 보고 의미를 유추할 수 있을 정도로 직관적이고 쉬운 문법을 가집니다. 다른 언어(예: 자바)에 비해 초보자가 배우기 매우 용이하며, 프로그래밍 경험이 있다면 일주일 만에도 충분히 배울 수 있을 만큼 쉽습니다.
• 무료이면서 강력함: 파이썬은 오픈 소스로 무료로 다운로드하여 사용할 수 있으며, 영리 목적으로 만든 프로그램도 판매 가능합니다. 파이썬은 쉽고 빠르지만 성능이 느리다는 단점이 있는데, 이를 보완하기 위해 속도가 빠른 C 언어와 잘 결합하여 사용할 수 있는 '접착 언어' 역할을 합니다. NumPy와 같이 C로 만들어진 라이브러리를 활용하면 파이썬에서도 빠른 속도 처리가 가능합니다. 최근에는 파이썬 문법을 기반으로 하면서도 훨씬 빠른 Mojo 언어 같은 대안도 등장하고 있습니다.
• 인터프리터 언어: 컴퓨터는 0과 1만 인식하며, 사람이 작성한 코드를 기계어로 번역해야 실행됩니다. 컴파일 언어(예: C)는 코드를 한 번에 번역하여 실행 파일(.exe)을 만든 후 실행하므로 빠릅니다. 반면 파이썬은 인터프리터 언어로, 코드를 한 줄씩 읽고 해석하여 실행하므로 컴파일 언어보다 느립니다.
• 간결함: 파이썬은 '가장 좋은 방법 한 가지만 이용하는 것'을 선호하며, 들여쓰기(indentation) 규칙이 매우 엄격하여 깔끔하게 코드를 정리하도록 강제합니다. 이는 초보자가 부수적인 개념(예: 자바의 public, class, void)을 몰라도 기능에만 집중할 수 있게 하여 프로그래밍을 즐길 수 있도록 돕습니다. 이로 인해 파이썬은 개발 속도가 매우 빠르다는 장점이 있습니다.
파이썬으로 할 수 있는 일:
• 웹 프로그래밍: Django, Flask, FastAPI 등의 프레임워크를 이용해 웹 백엔드 서버를 주로 개발하며, 최근에는 ReactPy와 같이 프론트엔드 개발(React 문법)도 파이썬으로 가능해지고 있습니다.
• 인공지능 및 머신러닝: TensorFlow, PyTorch와 같은 프레임워크가 파이썬 기반으로 가장 먼저 출시되므로 인공지능 분야에 파이썬이 필수적입니다.
• 수치 연산 및 데이터 분석: C 기반의 NumPy 라이브러리를 통해 행렬 계산 등 복잡한 수치 연산을 빠르게 처리할 수 있습니다. Pandas 라이브러리를 이용해 엑셀 데이터 처리, 연산, 그래프 그리기 등 데이터 분석 작업을 효율적으로 수행할 수 있습니다.
• 데이터베이스 프로그래밍: SQLite, MySQL 등 데이터베이스와 쉽게 소통하고 조작할 수 있습니다.
• 시스템 유틸리티: 하드디스크 최적화, 프로그램 삭제 관리 등 시스템 유틸리티를 개발하는 데 사용됩니다.
• GUI 프로그래밍: Tkinter 라이브러리를 이용해 클릭, 버튼 등 그래픽 사용자 인터페이스(UI)를 만드는 데 활용됩니다.
• 사물 인터넷(IoT): Raspberry Pi와 같은 인터넷 연결 디바이스를 파이썬으로 조작하여 스마트 스피커, 개인용 서버 등을 만들 수 있습니다. 파이썬은 다양한 분야에서 활용되지만, 시스템과 밀접한 프로그래밍 영역(운영체제 개발)이나 모바일 프로그래밍(앱 화면 개발)에는 적합하지 않습니다. 이러한 분야에는 C/C++, Java, Kotlin, Swift, JavaScript(React Native), Dart(Flutter) 등 다른 언어가 더 적합합니다.
파이썬 설치 및 실행:
1. 다운로드: 파이썬 공식 홈페이지(python.org)에서 원하는 버전(예: 3.11.2)을 다운로드합니다.
2. 중요한 설치 옵션: 설치 시 'Add Python 3.11 to PATH' 옵션을 반드시 체크해야 합니다. 'Customize installation'을 통해 모든 부가 기능을 설치하고, 설치 경로를 C:\Program Files\Python311과 같이 통일하는 것이 좋습니다.
3. 기본 실행 확인(REPL): 설치 완료 후 윈도우 검색창에 'python'을 입력하여 파이썬 실행 창(REPL: Read-Eval-Print Loop)이 뜨는지 확인합니다. print("Hello World")를 입력하여 잘 출력되는지 테스트합니다. REPL 종료는 quit() 또는 exit()를 사용합니다.
4. IDLE(통합 개발 환경): 파이썬 설치 시 기본으로 제공되는 에디터로, REPL 방식과 파일 생성/실행 기능을 모두 지원하며, 코드 색상 구분을 지원합니다. (IDLE 이름은 몬티 파이슨의 '에릭 아이들'에서 유래했습니다).
5. Visual Studio Code(VS Code) 설치: 가장 많이 사용되는 코드 에디터로, 공식 홈페이지에서 다운로드하여 설치합니다. VS Code는 메모장, 파일 탐색기, 터미널이 결합된 형태의 '통합 개발 환경(IDE)'입니다.
6. VS Code 활용:
    ◦ 폴더 열기: 'File' > 'Open Folder'로 작업 폴더(예: C:\python)를 엽니다.
    ◦ 파일 생성: 왼쪽 탐색기에서 새 파일 아이콘(+)을 클릭하거나 'File' > 'New File'을 통해 생성합니다.
    ◦ 파이썬 확장(Extension) 설치: 왼쪽 익스텐션 탭에서 'Python'을 검색하여 설치해야 합니다.
    ◦ 코드 실행: 확장 설치 후 오른쪽 상단의 'Run' (재생) 버튼을 클릭하여 코드를 실행합니다.
    ◦ 터미널에서 실행: VS Code의 통합 터미널(또는 CMD/PowerShell)에서 python your_file_name.py 명령어로 실행 가능합니다. PATH 설정 오류 시 '시스템 환경 변수 편집'에서 파이썬 설치 경로 및 Scripts 폴더를 PATH에 추가하여 해결합니다.
    ◦ 주석(Comments): #은 한 줄 주석, """...""" 또는 '''...'''은 여러 줄 주석을 만듭니다. Ctrl + /로 주석을 토글할 수 있습니다. 주석은 사람이 코드를 이해하기 위해 쓰는 텍스트로, 컴퓨터는 이를 무시하고 실행하지 않습니다.
    ◦ ChatGPT 활용: 코딩 중 오류 발생 시 ChatGPT에 코드와 문제점을 문의하면 디버깅, 코드 개선 등에 도움을 받을 수 있습니다. 질문의 정확도를 높이려면 영어로 질문하는 것이 더 효과적입니다.
파이썬 프로그래밍 기초: 자료형(Data Types): 자료형은 언어의 절반을 터득한 것이라 할 만큼 중요합니다. 같은 '1+1'이라도 자료형이 숫자면 '2'가 되고 문자열이면 '11'이 될 수 있습니다.
• 변수(Variables): 상자와 같이 값을 담는 공간으로 비유됩니다. 'A = 3'은 수학적 같다가 아니라 '3을 A라는 상자에 담는다'는 의미의 할당(Assignment)입니다. 'A = A + 1'은 A에 1을 더한 후 그 결과를 다시 A에 담는다는 의미입니다. 변수는 실제로는 메모리의 주소값을 담고 있으며, 이 주소에 실제 값이 저장됩니다.
    ◦ 변수 복사 시 주의: b = a처럼 직접 할당하면 a와 b가 같은 메모리 주소를 가리키게 되어, a에 저장된 mutable(변경 가능한) 자료형(예: 리스트)을 변경하면 b도 함께 변경됩니다. 이를 방지하려면 슬라이싱(b = a[:]), copy 모듈의 copy.copy(), 또는 리스트의 .copy() 메소드를 사용하여 값을 복사해야 합니다.
    ◦ 다중 할당: a, b = 1, 2 또는 [a, b] =와 같이 여러 변수에 동시에 값을 할당할 수 있습니다.
    ◦ 값 교환: a, b = b, a와 같이 임시 변수 없이 간편하게 두 변수의 값을 바꿀 수 있습니다.
    ◦ 지역 변수(Local Variable)와 전역 변수(Global Variable): 함수 안에서 선언된 변수는 '지역 변수'로, 함수가 끝나면 사라집니다. 함수 바깥에서 선언된 변수는 '전역 변수'로, 프로그램이 종료될 때까지 유지됩니다. 함수 내에서 전역 변수를 변경하려면 global 키워드를 사용해야 합니다. mutable 자료형(리스트 등)의 경우, 함수 내에서 객체 자체를 변경하는 메소드를 사용하면 global 키워드 없이도 전역 변수의 내용이 변경될 수 있습니다 (예: .append(), .pop()).
숫자형(Number Type): 정수형(int), 실수형(float)이 주로 사용됩니다.
• 사칙연산: +, -, *, /를 사용합니다.
• 제곱: ** (예: 3 ** 4는 3의 4승).
• 나머지: % (예: 7 % 3은 1).
• 몫: // (예: 7 // 3은 2).
문자열(String Type): 문자를 표현하는 자료형으로, 따옴표(작은따옴표, 큰따옴표, 삼중 따옴표)로 감싸서 만듭니다. 숫자를 따옴표로 감싸면 문자열이 됩니다.
• 따옴표 포함: 문자열 안에 따옴표를 포함하려면 다른 종류의 따옴표로 감싸거나, 백슬래시(\)로 이스케이프 처리합니다.
• 여러 줄 문자열: 삼중 따옴표("""...""" 또는 '''...''')를 사용하거나, \n (줄 바꿈)과 같은 이스케이프 코드를 사용합니다.
• 연결 및 반복: +로 연결하고 *로 반복합니다.
• 길이: len() 함수로 문자열의 길이를 구합니다 (공백 포함).
• 인덱싱(Indexing): 문자열의 특정 위치 문자를 가져옵니다. 0부터 시작하며, 음수 인덱스는 뒤에서부터 시작합니다 (-1은 마지막 문자).
• 슬라이싱(Slicing): 문자열의 특정 부분을 잘라 가져옵니다. [시작:끝:간격] 형태로, '끝' 인덱스는 포함되지 않습니다 (미만).
• 문자열 포맷팅(String Formatting): 문자열 내에 변수 값을 삽입하는 방법입니다.
    ◦ % 연산자: %d(정수), %s(문자열), %f(실수) 등을 사용합니다. %s는 모든 자료형을 수용 가능합니다.
    ◦ .format() 메소드: {} 중괄호에 인덱스나 이름을 지정하여 값을 삽입합니다.
    ◦ f-string (파이썬 3.6+ 권장): 문자열 앞에 f를 붙이고 중괄호 {} 안에 변수나 파이썬 표현식을 직접 넣어 사용합니다. 가장 간결하고 직관적입니다.
• 문자열 관련 함수(메소드):
    ◦ count(): 특정 문자(열)의 개수를 셉니다.
    ◦ find(): 특정 문자(열)의 첫 번째 인덱스를 반환하며, 없으면 -1을 반환합니다.
    ◦ index(): find()와 유사하지만, 없으면 오류를 발생시킵니다.
    ◦ join(): 특정 문자열을 구분자로 사용하여 리스트의 요소들을 연결합니다.
    ◦ upper(), lower(): 대문자/소문자로 변환합니다.
    ◦ lstrip(), rstrip(), strip(): 왼쪽/오른쪽/양쪽 공백을 제거합니다.
    ◦ replace(): 특정 문자열을 다른 문자열로 교체합니다.
    ◦ split(): 특정 구분자(기본값은 공백)를 기준으로 문자열을 리스트로 분리합니다.
리스트(List Type): 여러 개의 값을 순서대로 담는 서랍장 같은 자료형입니다.
• 생성: 대괄호 [] 안에 콤마로 구분된 요소들을 넣습니다. 서로 다른 자료형을 함께 담을 수 있습니다.
• 인덱싱 및 슬라이싱: 문자열과 거의 동일하게 작동합니다.
• 연산: +로 리스트를 연결하고 *로 리스트를 반복합니다. len()으로 길이를 구합니다.
• 변경 가능(Mutable): 리스트의 요소는 인덱스를 통해 값을 변경하거나(a[인덱스] = 값), del 키워드로 삭제할 수 있습니다.
• 리스트 관련 함수(메소드):
    ◦ append(): 리스트 맨 뒤에 요소를 추가합니다.
    ◦ extend(): 리스트에 다른 리스트나 iterable의 요소들을 확장하여 추가합니다.
    ◦ sort(): 리스트를 정렬합니다 (기본 오름차순).
    ◦ reverse(): 리스트의 순서를 뒤집습니다.
    ◦ insert(): 특정 인덱스 위치에 요소를 삽입합니다.
    ◦ remove(): 리스트에서 첫 번째로 나타나는 특정 값을 제거합니다.
    ◦ pop(): 리스트 맨 끝(또는 지정된 인덱스)의 요소를 꺼내고 제거합니다.
    ◦ count(): 리스트에서 특정 값의 개수를 셉니다.
    ◦ 자료형 변환: str(), int(), float(), list(), tuple(), dict(), set(), bool() 등을 사용하여 자료형을 변환할 수 있습니다. bool() 함수는 빈 문자열, 리스트, 튜플, 딕셔너리, 셋, 숫자 0, None은 False로, 그 외는 True로 판단합니다.
튜플(Tuple Type): 리스트와 매우 유사하지만, 한 번 생성되면 값을 변경할 수 없는(immutable) 자료형입니다.
• 생성: 소괄호 () 안에 콤마로 구분된 요소들을 넣습니다. 한 개의 요소를 가질 때는 반드시 콤마를 붙여야 합니다 (예: (1,)).
• 특징: 변경, 추가, 삭제가 불가능하며, 관련 메소드(sort(), append() 등)는 사용할 수 없습니다. +나 * 연산 시 새로운 튜플을 생성합니다.
딕셔너리(Dictionary Type): 사전처럼 '키(Key)'와 '값(Value)'의 쌍으로 데이터를 저장하는 자료형입니다.
• 생성: 중괄호 {} 안에 키: 값 형태로 요소를 넣습니다.
• 특징: 키는 중복될 수 없으며, 변경 불가능한 자료형(문자열, 숫자, 튜플 등)만 키로 사용할 수 있습니다.
• 추가/삭제: 딕셔너리[새 키] = 새 값으로 추가하고, del 딕셔너리[키]로 삭제합니다.
• 값 얻기: 딕셔너리[키] 또는 딕셔너리.get(키)를 사용합니다. get() 메소드는 키가 없을 때 None을 반환하거나 기본값을 지정할 수 있으며, [] 사용 시 KeyError가 발생합니다.
• 관련 함수(메소드):
    ◦ keys(): 모든 키를 모아 dict_keys 객체로 반환합니다.
    ◦ values(): 모든 값을 모아 dict_values 객체로 반환합니다.
    ◦ items(): 모든 키-값 쌍을 튜플 리스트 형태의 dict_items 객체로 반환합니다.
    ◦ clear(): 모든 키-값 쌍을 삭제합니다.
    ◦ in 연산자: 특정 키가 딕셔너리에 있는지 확인하여 True 또는 False를 반환합니다.
집합(Set Type): 수학의 집합과 같은 개념으로, 중복을 허용하지 않고 순서가 없는 자료형입니다.
• 생성: set() 함수로 리스트 등을 변환하거나, 중괄호 {} 안에 값들을 넣어 생성합니다 (키-값 쌍 없이).
• 특징: 순서가 없으므로 인덱싱이나 슬라이싱이 불가능합니다. 중복된 값은 자동으로 제거됩니다.
• 집합 연산:
    ◦ 교집합: & 연산자 또는 intersection() 메소드.
    ◦ 합집합: | 연산자 또는 union() 메소드.
    ◦ 차집합: - 연산자 또는 difference() 메소드.
• 관련 함수(메소드): add()로 한 개 값 추가, update()로 여러 개 값 추가, remove()로 특정 값 제거.
• 활용: 리스트의 중복된 값을 제거하는 데 유용하게 사용됩니다.
불(Boolean Type): 참(True)과 거짓(False)을 나타내는 자료형입니다.
• 활용: 주로 조건문(if)이나 반복문(while)에서 조건을 판단하는 데 사용됩니다.
• 표현: True, False (첫 글자 대문자).
• 참/거짓 속성: 파이썬의 각 자료형은 자체적으로 참 또는 거짓의 속성을 가집니다.
    ◦ 거짓(False): 빈 문자열, 빈 리스트, 빈 튜플, 빈 딕셔너리, 빈 셋, 숫자 0, None.
    ◦ 참(True): 위 경우를 제외한 모든 것 (값이 있는 문자열, 리스트, 튜플, 딕셔너리, 셋, 0이 아닌 숫자 등).
• bool() 함수: 특정 값의 참/거짓 속성을 확인할 때 사용합니다 (예: bool([])는 False).
프로그램의 구조(제어문):
• 조건문(Conditional Statements): 특정 조건이 참(True)인지 거짓(False)인지에 따라 다른 코드 블록을 실행합니다.
    ◦ if, elif, else: 기본적인 조건문 구조.
    ◦ 들여쓰기(Indentation): 파이썬에서 매우 중요하며, 코드 블록을 구분하는 역할을 합니다. 틀리면 IndentationError가 발생합니다.
    ◦ 콜론(:): if, elif, else 문장 끝에 반드시 붙여야 합니다.
    ◦ 비교 연산자: >, <, >=, <=, ==(같다), !=(같지 않다) 등을 사용합니다.
    ◦ 논리 연산자: and(모두 참), or(하나라도 참), not(반대)를 사용하여 복합 조건을 만듭니다.
    ◦ in, not in: 특정 요소가 시퀀스(리스트, 튜플, 문자열 등)에 포함되어 있는지 확인합니다.
    ◦ pass: 조건이 참일 때 아무것도 하지 않고 넘어갈 때 사용하는 키워드입니다.
    ◦ 조건부 표현식(Conditional Expression): 참일_때_값 if 조건 else 거짓일_때_값과 같이 한 줄로 조건을 표현할 수 있습니다 (가독성 때문에 실무에서는 주의해서 사용).
• 반복문(Loops): 특정 코드를 반복적으로 실행합니다.
    ◦ while 문: 조건이 참인 동안 코드 블록을 계속 반복합니다.
        ▪ 디버깅(Debugging): VS Code의 디버깅 기능(빨간 점 브레이크포인트, 'Run' > 'Start Debugging')을 통해 코드를 한 줄씩 실행하며 흐름과 변수 변화를 확인하는 것은 복잡한 반복문을 이해하는 데 매우 유용합니다. (디버깅의 유래는 실제 컴퓨터 내부 벌레(Bug)를 잡는 것에서 왔습니다).
        ▪ 복합 할당 연산자: +=, -=, *= 등은 변수 = 변수 + 값과 같은 연산을 축약하여 표현합니다 (예: a += 1).
        ▪ break: 반복문 내에서 break를 만나면, 해당 반복문을 즉시 종료하고 다음 코드로 넘어갑니다.
        ▪ continue: 반복문 내에서 continue를 만나면, 현재 반복을 중단하고 다음 반복으로 넘어갑니다 (아래 코드를 건너뜀).
        ▪ 무한 루프: while True:와 같이 조건이 항상 참이면 무한히 반복됩니다. Ctrl+C로 강제 종료할 수 있습니다. 무한 루프 내에서 객체를 지속적으로 생성하면 메모리 누수가 발생할 수 있으므로 주의해야 합니다.
    ◦ for 문: 리스트, 튜플, 문자열 등과 같이 여러 개의 값을 가진(iterable) 객체의 각 요소를 하나씩 순회하며 코드 블록을 반복합니다.
        ▪ for 변수 in iterable_객체: ... 형태로 사용합니다.
        ▪ range() 함수: 연속된 숫자를 생성하여 for 문과 함께 자주 사용됩니다 (예: range(시작, 끝_미만)). range(1, 11)은 1부터 10까지의 숫자를 생성합니다.
        ▪ 중첩 for 문: 반복문 안에 또 다른 반복문을 넣을 수 있습니다 (예: 구구단).
        ▪ print() 함수의 end 매개변수: print()는 기본적으로 출력을 마친 후 줄 바꿈(\n)을 합니다. end=''나 end=' ' 등을 사용하여 줄 바꿈 대신 다른 문자를 추가하거나 공백으로 연결할 수 있습니다.
        ▪ 리스트 컴프리헨션(List Comprehension): [표현식 for 변수 in iterable if 조건]과 같이 리스트를 한 줄로 간결하게 생성하는 방법입니다. 가독성을 높일 수 있는 '패션 코딩' 중 하나입니다.
함수(Functions): 특정 작업을 수행하는 코드 블록으로, 입력을 받아 처리하고 결과를 반환할 수 있습니다. 코드 재사용, 기능 분리, 가독성 향상에 기여합니다.
• 구조: def 함수명(매개변수): ... return 결과. def는 함수 정의를 위한 예약어입니다.
• 매개변수(Parameters)와 인수(Arguments): 함수 정의 시 받는 변수를 '매개변수', 함수 호출 시 전달하는 실제 값을 '인수'라고 합니다 (용어는 혼용되기도 함).
• 입력/출력 유무: 함수는 입력값이 없을 수도 있고, 리턴값이 없을 수도 있으며, 둘 다 없을 수도 있습니다. 리턴값이 없는 함수는 암묵적으로 None을 반환합니다.
• 매개변수 지정 호출: 함수명(변수명=값) 형태로 매개변수 이름을 직접 지정하여 호출할 수 있습니다. 이 경우 순서와 상관없이 전달됩니다.
• 가변 인자(Variable Arguments):
    ◦ *args: 몇 개의 인수가 올지 모를 때 모든 위치 인수를 튜플 형태로 받습니다.
    ◦ **kwargs: 키-값 형태로 몇 개의 인수가 올지 모를 때 모든 키워드 인수를 딕셔너리 형태로 받습니다.
• 리턴 값은 항상 하나: 함수는 한 번에 하나의 값만 리턴할 수 있습니다. 여러 값을 return a, b처럼 리턴하면 실제로는 튜플 하나를 리턴하는 것입니다. return 문을 만나면 함수 실행이 즉시 종료됩니다.
• 함수 빠져나가기: return을 사용하여 특정 조건에서 함수를 일찍 종료할 수 있습니다.
• 매개변수 초기값 설정: def 함수명(매개변수=초기값): 형태로 기본값을 설정할 수 있습니다. 초기값이 있는 매개변수는 항상 맨 뒤에 정의해야 합니다.
• 람다(Lambda) 함수: 한 줄로 간결하게 함수를 정의하는 익명 함수입니다. lambda 매개변수: 표현식 형태로 사용하며, 짧은 함수를 만들 때 유용합니다. 실무에서도 간결성을 위해 많이 사용됩니다.
사용자 입출력:
• input() 함수: 사용자로부터 키보드 입력을 받습니다. 기본적으로 모든 입력은 문자열(string)로 처리되므로, 숫자가 필요한 경우 int()나 float() 등으로 형 변환해야 합니다. 안내 문구를 함께 표시할 수 있습니다.
• print() 함수: 화면에 데이터를 출력합니다. 여러 값을 콤마로 구분하여 전달하면 기본적으로 공백으로 구분되어 출력됩니다. end 매개변수를 사용하여 출력의 끝 문자(기본값은 줄 바꿈)를 변경할 수 있습니다.
파일 읽고 쓰기:
• open() 함수: 파일을 열 때 사용합니다. open('파일명', '모드') 형태로 사용합니다.
    ◦ 파일 모드:
        ▪ 'w' (write): 쓰기 모드로 파일을 엽니다. 파일이 없으면 새로 생성하고, 있으면 기존 내용을 덮어씁니다.
        ▪ 'r' (read): 읽기 모드로 파일을 엽니다.
        ▪ 'a' (append): 추가 모드로 파일을 엽니다. 파일이 없으면 새로 생성하고, 있으면 기존 내용 뒤에 추가합니다.
• write() 메소드: 열린 파일 객체에 문자열을 씁니다.
• close() 메소드: 파일 사용 후 반드시 파일을 닫아 리소스를 해제해야 합니다.
• 인코딩(Encoding): 한글 등 비(非)ASCII 문자를 파일에 쓸 때 encoding='utf-8' (또는 euc-kr)을 지정해야 문자 깨짐을 방지할 수 있습니다. 파일을 읽을 때도 동일한 인코딩 방식을 사용해야 합니다.
• 읽기 메소드:
    ◦ readline(): 파일에서 한 줄을 읽습니다.
    ◦ readlines(): 파일의 모든 줄을 읽어 리스트 형태로 반환합니다.
    ◦ read(): 파일의 전체 내용을 하나의 문자열로 읽습니다.
    ◦ for 문으로 파일 객체를 직접 순회하면 한 줄씩 읽을 수 있습니다.
• with 문: with open(...) as f: 형태로 사용하면 파일 작업을 마친 후 자동으로 파일을 닫아주므로 close()를 명시적으로 호출할 필요가 없어 편리합니다.
명령어 프롬프트(Command Line) 입출력:
• sys 모듈: 파이썬 스크립트 실행 시 전달되는 명령행 인자(argument)들을 처리하기 위해 import sys를 사용합니다.
• sys.argv: 명령행 인자들이 리스트 형태로 담겨 있습니다. sys.argv는 스크립트 파일 이름 자체이고, 이후 인자들은 sys.argv, sys.argv 등으로 접근합니다. 모든 인자는 문자열이므로, 필요에 따라 형 변환해야 합니다.
파이썬 날개 달기(심화): 클래스(Classes): 반복되는 변수(속성/Attribute)와 함수(메소드/Method)를 미리 정의해 놓은 '설계도' 또는 '틀'의 개념입니다.
• 객체(Object) / 인스턴스(Instance): 클래스라는 설계도를 바탕으로 실제로 만들어낸 결과물을 '객체' 또는 '인스턴스'라고 부릅니다. 객체는 항상 **값(변수)**과 행동(함수) 두 가지를 지닙니다.
• 왜 필요한가: 유사한 기능을 여러 번 구현해야 할 때 코드 중복을 피하고 효율적으로 관리하기 위함입니다 (예: 여러 개의 계산기 만들기).
• 생성: class 클래스명: (클래스명은 대문자로 시작하는 것이 관례).
• 메소드: 클래스 안에 정의된 함수. 첫 번째 매개변수로 항상 self를 가집니다. self는 해당 메소드를 호출한 객체 자신을 의미하며, 파이썬에서는 명시적으로 self를 사용해야 합니다.
• 생성자(Constructor): __init__이라는 특별한 메소드. 객체가 생성될 때(인스턴스를 찍어낼 때) 자동으로 가장 먼저 실행되며, 주로 객체의 초기값을 설정하는 데 사용됩니다. __init__에 정의된 매개변수는 객체 생성 시 필수로 전달해야 합니다.
• 객체 변수(Instance Variables): self.변수명 형태로 정의되며, 각 객체(인스턴스)마다 고유하게 값을 가지는 변수입니다.
• 상속(Inheritance): 기존 클래스(부모 클래스)의 기능을 새로운 클래스(자식 클래스)가 물려받아 재사용하는 기능입니다. class 자식클래스명(부모클래스명): 형태로 정의합니다.
    ◦ 메소드 오버라이딩(Method Overriding): 자식 클래스에서 부모 클래스의 메소드를 재정의하여 자신의 동작을 구현하는 것을 의미합니다. 이 경우 자식의 메소드가 우선권을 가집니다.
• 클래스 변수(Class Variables): 클래스 내부에 정의되며, 해당 클래스로부터 생성된 모든 객체들이 공유하는 변수입니다.
모듈(Modules)과 패키지(Packages):
• 모듈: 함수, 변수, 클래스 등을 포함하는 파이썬 파일(.py)입니다. 다른 파이썬 파일에서 import하여 가져와 사용할 수 있습니다. import 모듈이름 또는 from 모듈이름 import 함수/클래스/변수 형태로 사용합니다.
• if __name__ == "__main__":: 모듈 파일이 직접 실행될 때만 특정 코드를 실행하고, 다른 파일에서 import될 때는 실행되지 않도록 하는 용도로 사용됩니다.
• 모듈 검색 경로: 파이썬은 모듈을 특정 경로에서 찾습니다. sys.path 리스트에 경로를 추가하여 모듈을 찾을 수 있습니다.
• 패키지: 여러 모듈을 체계적으로 묶어 놓은 디렉토리입니다. 일반적으로 디렉토리 내에 __init__.py 파일이 있으면 패키지로 인식합니다. import 패키지.모듈 형태로 사용합니다.
• 별칭(Alias): import 모듈 as 별칭과 같이 모듈이나 패키지에 별칭을 부여하여 짧게 사용할 수 있습니다 (예: import sys as s).
예외 처리(Exception Handling): 프로그램 실행 중 발생하는 오류(예외)를 처리하여 프로그램이 비정상적으로 종료되는 것을 방지하는 기법입니다.
• 오류 발생: '없는 파일 열기(FileNotFoundError)', '0으로 나누기(ZeroDivisionError)', '리스트 인덱스 범위 초과(IndexError)' 등 다양한 오류가 있습니다.
• try-except-else-finally 구조:
    ◦ try: 오류가 발생할 가능성이 있는 코드를 작성합니다.
    ◦ except: try 블록에서 특정 오류가 발생했을 때 실행할 코드를 작성합니다. 특정 오류 유형을 지정하거나, 모든 오류를 처리할 수 있습니다. as e를 사용하여 오류 객체를 받아 처리할 수 있습니다.
    ◦ else: try 블록에서 오류가 발생하지 않았을 때만 실행되는 코드입니다.
    ◦ finally: try 블록의 성공/실패 여부와 관계없이 항상 마지막에 실행되는 코드입니다 (예: 파일 닫기).
• pass 사용: except 블록에 pass를 사용하여 오류가 발생해도 아무것도 하지 않고 넘어가게 할 수 있습니다.
• raise: 프로그래머가 의도적으로 특정 오류를 발생시킬 때 사용합니다 (예: 특정 조건이 충족되지 않을 때 경고).
• 사용자 정의 예외: Exception 클래스를 상속받아 자신만의 예외 클래스를 만들 수 있습니다.
내장 함수, 표준 라이브러리, 외부 라이브러리:
• 내장 함수(Built-in Functions): 파이썬에 기본적으로 내장되어 있어 import 없이 바로 사용할 수 있는 함수들입니다 (예: print(), input(), len(), type(), abs(), int(), str(), bool(), enumerate(), divmod(), id() 등). 개발자는 '바퀴를 다시 만들지 말라(Don't reinvent the wheel)'는 원칙에 따라 이미 있는 기능을 재사용하는 것이 좋습니다.
• 표준 라이브러리(Standard Libraries): 파이썬에 기본으로 포함되어 있지만, 사용 시 import해야 하는 모듈들입니다 (예: datetime - 날짜/시간 처리, time - 시간 관련 기능, math - 수학 함수 등). time.sleep(초) 함수는 특정 시간 동안 프로그램 실행을 일시 중지시키는 데 사용됩니다.
• 외부 라이브러리(External Libraries): 파이썬에 기본으로 포함되어 있지 않으며, 다른 개발자들이 만들어 인터넷에 공개한 라이브러리입니다.
    ◦ pip: 파이썬 모듈이나 패키지를 쉽게 설치/삭제할 수 있도록 도와주는 도구입니다. pip install 패키지명, pip uninstall 패키지명, pip list 등으로 사용합니다.
    ◦ PyPI (Python Package Index): 파이썬 패키지들이 모여 있는 저장소입니다.
    ◦ 활용: 외부 라이브러리마다 사용법이 다르므로, 공식 문서, 구글링, 또는 ChatGPT를 통해 사용법을 익혀야 합니다 (예: Faker - 가짜 데이터 생성). VS Code와 같은 IDE에서 코드 자동 완성이나 함수 정의 미리보기 기능을 활용하면 편리합니다.
실제 문제 해결 연습:
• 프로그래밍 사고 흐름: 프로그램을 만들 때는 **입력(Input)**과 **출력(Output)**을 먼저 생각하는 것이 좋습니다.
• 예시 문제 해결:
    ◦ 구구단 2단 출력: 반복문(for 또는 while)을 활용하여 1부터 9까지 반복하며 곱셈 결과를 리스트에 추가합니다.
    ◦ 3과 5의 배수 합산: 1부터 999까지의 숫자를 순회하며 % 연산자를 이용해 3 또는 5의 배수인지 확인하고 합산합니다. 이때 중복 합산을 피하기 위해 or 조건으로 연결합니다.
    ◦ 게시판 페이징: 총 게시물 수와 페이지당 게시물 수를 입력받아 총 페이지 수를 계산합니다. 나눗셈(//)과 나머지(%) 연산자를 활용하여, 딱 나누어떨어지는 경우와 그렇지 않은 경우를 구분하여 처리합니다.
    ◦ 간단한 메모장: 명령행 인자(sys.argv)를 통해 옵션(-a 추가, -v 조회)과 메모 내용을 받아 파일에 추가하거나(append mode) 읽어(read mode) 출력하는 기능을 구현합니다.
    ◦ 탭 문자를 공백 4개로 바꾸기: 파일을 읽어 내용을 가져온 후, 문자열의 replace() 메소드를 사용하여 탭 문자(\t)를 공백 4개(' ' * 4)로 교체한 다음 새 파일로 저장합니다.
    ◦ 하위 디렉토리 파이썬 파일 검색: os 모듈의 os.listdir(), os.path.join(), os.path.splitext(), os.path.isdir() 등을 사용하여 특정 디렉토리와 그 하위 디렉토리 내의 .py 파일을 찾습니다. 재귀 함수(함수가 자기 자신을 호출)를 사용하거나, os.walk()와 같은 효율적인 메소드를 활용할 수 있습니다.
파이썬 심화 내용:
• 유니코드: 컴퓨터가 문자를 인식하기 위한 표준으로, 아스키 코드의 한계를 넘어 전 세계 모든 문자를 포함하도록 설계되었습니다. 파이썬 3부터는 모든 문자열을 기본적으로 유니코드로 처리합니다. **인코딩(Encoding)**은 문자열을 바이트(컴퓨터가 읽는 형태)로 변환하고, **디코딩(Decoding)**은 바이트를 다시 문자열로 변환하는 과정입니다. 이 과정에서 올바른 인코딩 방식을 사용해야 합니다.
• 클로저(Closure)와 데코레이터(Decorator):
    ◦ 클로저: 함수 안에 내부 함수를 정의하고, 그 내부 함수를 리턴하는 함수입니다. 내부 함수는 외부(클로저) 함수의 지역 변수에 접근할 수 있습니다. 특정 값을 고정한 함수를 생성하는 데 유용합니다.
    ◦ 데코레이터: 기존 함수의 코드를 변경하지 않고 기능을 추가하는 방법입니다. 클로저를 활용하며, @데코레이터_함수명 문법으로 함수 위에 붙여 사용합니다. 주로 함수의 실행 시간 측정, 로깅 등 공통 기능을 적용할 때 사용됩니다.
• 이터레이터(Iterator)와 제너레이터(Generator):
    ◦ 이터레이터: next() 함수를 호출할 때마다 다음 값을 하나씩 반환하며, 더 이상 값이 없으면 StopIteration 예외를 발생시키는 객체입니다. iter() 함수로 리스트 등 반복 가능한 객체를 이터레이터로 만들 수 있습니다. 이터레이터는 한 번 소비하면 다시 사용할 수 없는 특징이 있습니다.
    ◦ 제너레이터: 이터레이터를 생성해 주는 함수입니다. yield 키워드를 사용하여 값을 반환하며, yield가 호출될 때마다 함수 실행이 일시 중지되고, next() 호출 시 중지된 지점부터 다시 실행됩니다. 메모리 효율적이며, '느긋한 계산법(Lazy Evaluation)'에 적합합니다. '제너레이터 표현식'으로 리스트 컴프리헨션과 유사한 방식으로 간결하게 만들 수 있습니다.
• 파이썬 타입 어노테이션(Type Annotation): 파이썬 3.5부터 변수와 함수의 타입에 대한 '힌트'를 제공하는 기능입니다.
    ◦ 동적 vs. 정적 언어: 파이썬은 실행 중 변수 타입이 바뀔 수 있는 '동적 언어'입니다. 반면 자바 같은 '정적 언어'는 컴파일 시점에 타입이 고정됩니다.
    ◦ 목적: 코드 가독성 향상 및 정적 분석 도구(예: MyPy)를 통해 개발 단계에서 잠재적 오류를 발견하는 데 도움을 줍니다. 실제 실행 시 타입 검사를 강제하지는 않습니다. MyPy와 같은 외부 라이브러리를 설치하면 타입 불일치 시 오류를 띄울 수 있습니다.
• 정규 표현식(Regular Expressions - RegEx): 복잡한 문자열에서 특정 패턴을 찾거나 변환하는 데 사용하는 강력한 기법입니다. 파이썬 고유의 문법이 아니며, re 모듈을 통해 사용합니다.
    ◦ 메타 문자: ., *, +, ?, [], ^, $, |, (), \ 등 특별한 의미를 가지는 문자들입니다.
    ◦ 주요 메소드:
        ▪ re.compile(패턴): 정규식 패턴 객체를 생성합니다.
        ▪ match(): 문자열의 처음부터 패턴과 일치하는지 검사합니다.
        ▪ search(): 문자열 전체에서 패턴과 일치하는 부분이 있는지 탐색합니다.
        ▪ findall(): 패턴과 일치하는 모든 부분을 리스트로 반환합니다.
        ▪ finditer(): 패턴과 일치하는 모든 부분을 매치 객체 이터레이터로 반환합니다.
        ▪ sub(교체할_문자열, 대상_문자열, [횟수]): 패턴과 일치하는 부분을 다른 문자열로 바꿉니다.
    ◦ 매치 객체(Match Object): match()나 search() 성공 시 반환되며, group(), start(), end(), span() 등의 메소드를 통해 매치된 정보(문자열, 위치 등)를 얻을 수 있습니다.
    ◦ 컴파일 옵션: re.S(DOTALL), re.I(IGNORECASE), re.M(MULTILINE), re.X(VERBOSE) 등으로 정규식의 동작 방식을 설정할 수 있습니다.
    ◦ 원시 문자열(Raw String): r'...' 접두사를 사용하여 백슬래시(\)를 특별한 의미 없이 문자 그대로 해석하게 합니다.
    ◦ 그룹핑(()): 정규식의 특정 부분을 묶어 서브 패턴으로 만들고, 이를 추출하거나 재참조할 수 있습니다. 이름을 붙이는 '명명 그룹'도 가능합니다.
    ◦ 전방 탐색(Lookahead): 패턴에는 포함되지만 실제 매치 결과에는 포함되지 않는 조건((?=...) 긍정, (?!...) 부정)을 설정할 수 있습니다.
    ◦ 탐욕적(Greedy) vs. 비탐욕적(Non-Greedy) 매치: *, +, {}와 같은 반복 문자는 기본적으로 가능한 한 길게 매치하려는 '탐욕적' 특성을 가집니다. 뒤에 ?를 붙여 *?, +?처럼 사용하면 가능한 한 짧게 매치하는 '비탐욕적'으로 동작합니다.
